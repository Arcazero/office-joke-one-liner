One original one-line joke about office life — an entry for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty ($5 in USDC).

## The joke

> I finally reached inbox zero — by forwarding every email to the coworker who quit last Tuesday.

95 characters, one line. The full line also lives in `joke.txt`.

## Run it

```sh
python3 main.py
```

`main.py` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
